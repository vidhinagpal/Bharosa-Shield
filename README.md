# Bharosa Shield (भरोसा शील्ड)

Bharosa Shield is a browser based digital safety prototype designed to help people recognize common online scams and understand warning signs in everyday documents. It gives clear, voice friendly guidance and encourages users to check important decisions with someone they trust.

## Features

- Check suspicious messages and links for common scam warning signs.
- Review sample loan, land, and job documents for risky clauses.
- Hear guidance using the browser’s text to speech support.
- Use the interface in Hindi, English, Marathi, Tamil, Telugu, and Bengali.
- Explore trusted contact, cybercrime reporting, demo walkthrough, and scam awareness simulations.
- Switch between light and dark themes.

## Run locally

No build step is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Allow microphone access if you want to try voice input.

Some browser features, including speech recognition, depend on browser support and permissions.

## How it works

This project is a front end prototype built with HTML, CSS, and JavaScript. Message checks use local rule based examples and heuristics. Some interface flows, such as document image analysis and family replies, are demonstrations rather than connected services.

## Important

Bharosa Shield provides general awareness guidance, not a guarantee that a message or document is safe or unsafe, legal advice, or an official determination. Verify important requests through independently confirmed channels. If you suspect financial cyber fraud in India, contact the national cybercrime helpline at **1930** and follow official reporting guidance.
